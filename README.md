# 🎴 Jogo de Cartas – Tabuleiro Tático

Este projeto é um **jogo de cartas com tabuleiro**, inspirado em mecânicas de jogos como *Yu-Gi-Oh!*, desenvolvido **inteiramente na Godot Engine** utilizando **GDScript**.

A proposta é unir estratégia de cartas com movimentação e posicionamento em um tabuleiro, criando partidas que exigem planejamento, leitura do adversário e boas decisões a cada turno.

---

## 🧠 Conceito do Jogo

- Jogo de cartas com foco estratégico  
- Combate baseado em turnos  
- Tabuleiro como elemento central da jogabilidade  
- Cartas com efeitos, ataques e habilidades especiais  
- Sistema pensado para expansão futura (novas cartas, regras e modos)

O jogador precisa administrar seu deck, posicionar unidades no tabuleiro e usar as cartas no momento certo para vencer.

---

## 🛠️ Tecnologias Utilizadas

- **Godot Engine**
- **GDScript**
- Desenvolvimento feito 100% dentro da engine  
- Sem uso de frameworks externos
